🚀 Featured Projects
Lab 02 — Image Processing Fundamentals

Explores digital images as pixel arrays, implementing point operations, convolution-based filters, histogram equalization/CLAHE, and geometric transforms with OpenCV/Pillow/NumPy. Then connects these hand-built operations to how CNNs actually process images.

Lab 03 — Classical ML in Computer Vision

This project explores face recognition on the Olivetti Faces dataset without using deep learning. It applies HOG and LBP feature extraction techniques with SVM and Random Forest classifiers to evaluate traditional computer vision approaches. The best-performing model, SVM with HOG features, achieved 95.0% held-out test accuracy. A deliberate 1-Nearest Neighbor (1-NN) experiment was also conducted to demonstrate why achieving 100% training accuracy does not necessarily guarantee strong generalization to unseen data.

Lab 04 — Chihuahua or Muffin? (Fully-Connected NN)

A from-scratch fully-connected PyTorch network tackling the classic "chihuahua vs. muffin" image classification challenge, reaching 83.3% final validation accuracy as a baseline before introducing convolutional layers.

Lab 05 — Chihuahua or Muffin with CNN

Rebuilds the Lab 04 task with a custom convolutional neural network (3 conv blocks + dropout), boosting peak validation accuracy to 96.7% and directly comparing against the dense-network baseline.

Lab 06 — Object Detection using Transfer Learning (YOLO11)

This lab compares zero-shot inference, frozen-backbone feature extraction, and full fine-tuning strategies using Ultralytics YOLO11 on the COCO8 dataset. It evaluates the tradeoffs between these approaches by measuring performance using mean Average Precision (mAP), precision, and recall to determine how each strategy impacts object detection accuracy and generalization.

Lab 08 — Vision-Language Models (VLMs)

This project investigates the inner workings of SmolVLM-500M-Instruct, including Vision Transformer (ViT) patch tokenization and prompt-driven task switching for different applications such as classification, counting, and image description. It also explores practical uses of vision-language models, including alt-text generation and chart interpretation, while evaluating model reliability through a hallucination “trap question” audit.
